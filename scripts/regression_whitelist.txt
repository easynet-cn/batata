# Known-failure whitelist for scripts/regression.sh
#
# Format:  <stage>|<pattern>|<reason>
#
# <pattern> is matched as a substring of the failing item's name (for `unit`,
# that is `crate::test::path`; for `integration`/`matrix`, `<suite>: <name>`).
# Anything that does NOT match an entry here BLOCKS the gate.
#
# Rules for editing this file:
#   - Every entry needs a reason and the date it was observed. An entry without
#     a reason is a suppressed bug, not a baseline.
#   - Prefer narrowing the pattern to the specific test, never to a whole crate.
#   - When you fix one of these, delete the line in the same commit — otherwise
#     the gate silently starts passing a test that no longer runs.
#
# Stages: fmt | check | unit | integration | matrix | perf
